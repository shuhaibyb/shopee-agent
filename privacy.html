Kebijakan Privasi — Shopee Agent

Terakhir diperbarui: 26 Oktober 2026

Data yang diakses

Shopee Agent meminta izin Google Sheets dan Google Drive hanya untuk:

  • menambah dan memperbarui baris data resi di Google Sheet milik pemilik aplikasi;
  • mengunggah file resi (PDF) ke folder Google Drive milik pemilik aplikasi.

Penggunaan dan penyimpanan

Data hanya dipakai untuk keperluan operasional toko kami sendiri. Token akses Google disimpan di komputer pemilik aplikasi dan tidak dikirim ke server pihak lain.

Berbagi data

Kami tidak menjual, menyewakan, atau membagikan data Google pengguna kepada pihak ketiga mana pun.

Menghapus akses

Akses dapat dicabut kapan saja melalui myaccount.google.com/permissions.
